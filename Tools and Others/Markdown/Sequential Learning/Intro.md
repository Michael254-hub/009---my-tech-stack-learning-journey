# Introduction to Markdown
Markdown is a lightweight markup language.

It uses .md or .markdown extension.

It is very essential while writing documentations and theoretical content while in need of basic formatting.

I've mostly used in code documentations and partly while creating markdown blogs which I'm still experimenting.

It has been useful is bringing out neat and well strucrured documentations.

---

### Markdown formatting:
- Headings (#)
- Bold Text (**)
- Italicized Text (*)
- Blockquote (>)
- Lists (Ordered and unordered) (Numbers - ordered/ Hyphen - unordered)
- Code (`)
- Horizontal Line (---)
- Links ([Title](Link))
- Images (![Alt Text](image.png))
- Fenced Code Block (```)
- Definition List 
- Strikethrough 
- Task List ([])
- Subscript
- Superscript

In the paranthesis are the marldown symbols for the various use cases.
